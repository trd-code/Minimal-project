# กระดานวาด (Draw Board)

แอปเว็บสำหรับ **เขียน/วาดบนหน้าจอโทรศัพท์** คล้ายการเขียนบนสไลด์ PowerPoint
ทำงานแบบ PWA เปิดในเบราว์เซอร์มือถือได้ทันที และ **ติดตั้งลงหน้าจอโฮมเป็นแอปได้**

## ฟีเจอร์

- ✏️ วาดด้วยนิ้ว/ปากกา Stylus เส้นลื่นไหล (รองรับ high-DPI)
- 🖍️ ปากกาเน้นข้อความ (Highlighter) และ 🧽 ยางลบ
- 🎨 เลือกสีได้ 7 สี และปรับขนาดเส้นด้วยแถบเลื่อน
- 📑 หลายสไลด์ (เพิ่ม/ลบ/เลื่อนไปมา) เหมือน PowerPoint
- ↶ ↷ เลิกทำ / ทำซ้ำ
- 🖼️ พื้นหลังสีขาว / สีเข้ม / แบบตาราง
- ⤓ บันทึกสไลด์เป็นรูป PNG
- 💾 บันทึกงานอัตโนมัติในเครื่อง (localStorage) — เปิดใหม่งานยังอยู่
- 📴 ใช้งานออฟไลน์ได้ (Service Worker)

## วิธีใช้งาน

### บนคอมพิวเตอร์ (ทดสอบ)
เปิดเซิร์ฟเวอร์ในโฟลเดอร์นี้ แล้วเข้าจากเบราว์เซอร์:

```bash
# ต้องรันผ่านเซิร์ฟเวอร์ (Service Worker ต้องใช้ http/https)
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

### บนโทรศัพท์
1. นำไฟล์ทั้งหมดไปวางบนโฮสติ้งที่เป็น HTTPS (เช่น GitHub Pages, Netlify, Vercel)
2. เปิด URL ในเบราว์เซอร์มือถือ
3. กด **"เพิ่มไปยังหน้าจอโฮม" / "Add to Home Screen"** เพื่อติดตั้งเป็นแอป

> เปิดผ่าน GitHub Pages ได้เลยหลัง push: ไปที่ Settings → Pages → เลือก branch แล้ว publish

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | โครงหน้าและปุ่มต่าง ๆ |
| `style.css` | สไตล์ (ออกแบบสำหรับมือถือ) |
| `app.js` | ตรรกะการวาด, สไลด์, undo/redo, บันทึก |
| `manifest.json` | ข้อมูลแอปสำหรับติดตั้ง (PWA) |
| `sw.js` | Service Worker สำหรับใช้งานออฟไลน์ |
| `icon.svg` | ไอคอนแอป |
