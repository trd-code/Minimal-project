# วาดทับหน้าจอ (Screen Draw) — แอป Android

แอป Android แท้ที่ **ขีดเขียน/วาดลอยทับได้ทุกแอปและทุกหน้าจอ** โดยใช้สิทธิ์
"แสดงบนแอปอื่น" (Display over other apps) พร้อมแถบเครื่องมือลอยที่ลากย้ายได้

## ฟีเจอร์
- ✏️ วาดลอยทับทุกแอป / หน้าโฮม / หน้าจอใดก็ได้
- ✋ สลับโหมด "วาด" ↔ "แตะทะลุ" (ใช้แอปข้างล่างต่อโดยยังเห็นเส้นที่วาดไว้)
- 🎨 เปลี่ยนสี 8 สี
- ↶ ลบเส้นล่าสุด / 🗑 ล้างทั้งหมด
- ⠿ ลากย้ายแถบเครื่องมือได้
- ทำงานเป็น foreground service มีปุ่มหยุดในแถบแจ้งเตือน

> ⚠️ ใช้ได้เฉพาะ **Android** (เวอร์ชัน 8.0 ขึ้นไป) — iOS ทำแบบนี้ไม่ได้

## วิธีได้ไฟล์ APK (ไม่ต้องมี Android Studio)
โปรเจกต์นี้มี GitHub Actions ที่ build APK ให้อัตโนมัติ:
1. ไปที่แท็บ **Actions** ของ repo → เลือก workflow **"Build Android APK"**
2. เปิด run ล่าสุดที่ขึ้นเครื่องหมายถูกสีเขียว
3. เลื่อนลงล่างสุดหัวข้อ **Artifacts** → ดาวน์โหลด **`screendraw-debug-apk`**
4. แตกไฟล์ zip จะได้ `app-debug.apk`

## วิธีติดตั้งบนมือถือ
1. โอนไฟล์ `app-debug.apk` เข้าเครื่อง แล้วแตะเปิด
2. อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" (Install unknown apps) ให้เบราว์เซอร์/ไฟล์แมเนเจอร์
3. ติดตั้งแล้วเปิดแอป → กด **เริ่มวาดทับหน้าจอ**
4. ครั้งแรกจะพาไปหน้าตั้งค่า — เปิดสิทธิ์ **"แสดงบนแอปอื่น"** ให้แอปนี้ แล้วกลับมากดเริ่มอีกครั้ง

## โครงสร้าง
| ส่วน | ไฟล์ |
|------|------|
| หน้าหลัก + ขอสิทธิ์ | `MainActivity.kt` |
| บริการโอเวอร์เลย์ + แถบเครื่องมือ | `OverlayService.kt` |
| ตัววาดเส้นบน Canvas | `DrawingView.kt` |

## หมายเหตุ
เป็น **debug APK** (ยังไม่เซ็นเพื่อขึ้น Play Store) เหมาะกับติดตั้งใช้เองในเครื่อง
